# Nikitha Sunkara — React Portfolio

A responsive portfolio made with React + Vite.

## Run locally
1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. In the terminal run `npm install` and then `npm run dev`.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder (not the ZIP itself).
2. Sign in to Vercel with GitHub and choose **Add New → Project**.
3. Import the portfolio repository. Vercel should detect Vite automatically.
4. Click **Deploy**. When finished, copy the public `vercel.app` URL and send it to the interviewer.

## Before submitting
- Replace the portrait placeholder in the hero with a professional photo. Save it as `public/images/nikitha.jpg`, then in `src/main.jsx` replace the `portrait-placeholder` div with `<img className="portrait-photo" src="/images/nikitha.jpg" alt="Nikitha Sunkara" />`.
- Replace the three `*-placeholder.svg` project preview images in `public/images/` with screenshots of your own actual projects. Keep the filenames the same, or update the image paths in `src/main.jsx`.
- Check every GitHub link and make sure you can explain your actual contribution to each project.
- Update project technologies/descriptions if any detail does not match your work.

No fake live-demo links are included; the project cards link to GitHub repositories.
